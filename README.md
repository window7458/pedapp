# SayEye — 시각장애인 보행 보조 앱 (웹앱 + 서버)

스마트폰 하나로 앞을 보고, 위험이 다가오면 먼저 말로 알려 주는 보행 보조 앱이다. 인하대 인공지능공학과 캡스톤 Team Insight.

- 앱 · 서버 설명, 실행 방법, 기능 목록: [`code/app/README.md`](code/app/README.md)
- 배포(Google Cloud Run GPU): `deploy/` (`deploy_all.ps1`, 키 값은 저장소 밖 설정 파일에서 읽음)
- 화면 시험: `code/app/tests/web/`

팀 모델 학습 · 트리거 원본 · 전체 정리는 팀 저장소의 `final` 브랜치에 있다.
