## 이 브랜치에 들어간 것 (모두 테스트 통과, 실제 폰 확인은 아직)
- Cloud Run 배포: `Dockerfile`, `.gcloudignore`, `deploy/deploy_cpu.ps1`(배포됨, 서울), `deploy/deploy_gpu.ps1`(아직 안 돌림, 도쿄 L4). 데이터(보호자 연결 · 처음 설정 · 알림 30일 · 음성 캐시)는 버킷을 `/data`(DATA_DIR)에 붙여 둔다. 배포 명령은 Claude 자동 모드가 막아서 사용자가 PowerShell에서 실행한다.
- 보호자 연결: 보행자 "보호자 연결해줘" → QR(1회용 10분) → 보호자 폰이 토큰을 받아 계속 연결. 6자리 번호는 보조. `tests/pairing_test.py`
- 사생활: 평소엔 알림만. 위치 · 영상은 SOS/넘어짐(30분 자동), 보호자 요청 + 보행자 "허락"(10분), 만 13세 미만(항상). 보는 중이면 보행자에게 알림. 기록 30일 보관. `tests/privacy_test.py`
- 처음 설정: 만 나이 · 키 · 카메라 위치 → 카메라 높이(키×비율, 트리거 `ego_motion.CAM_H`를 바깥에서 설정, 트리거 코드는 안 고침). 13세 미만 해제는 보호자 화면에서만. `tests/profile_test.py`
- 넘어짐 감지(폰 가속도, 30초 무응답 → SOS), 안내 멈춤 4초 알림, "알림 보내줘", 보호자 → 보행자 음성 메시지.
- 절전: 안내 중이 아니면 90초 뒤 연결 끊기(보호자 화면은 숨기고 1분) → GPU 가 혼자 돌며 요금이 나가지 않게.
- 디자인 세부: Pretendard 서브셋 글꼴, 질감, 그림자, 상태 전환, 다크 모드 글자색 수정, 새 사람 실루엣 픽토그램, 아이콘.
- 앱 음성: `code/app/app_tts.py` + `/api/tts` → Google Cloud TTS `ko-KR-Chirp3-HD-Zephyr`(사용자가 고름, 샘플 04). 자주 하는 말 42개는 앱이 연결되면 미리 받고, 처음 문장은 0.9초 안에 못 받으면 폰 기본 음성. 트리거 쪽은 윈도우 Heami인데 리눅스 서버에선 못 써서 앱은 Zephyr.
