# SayEye 앱 (서버는 노트북/GPU, 보행자 · 보호자는 폰 브라우저)

시각장애인 보행 보조: **폰 카메라 또는 라즈베리파이 카메라의 실시간 영상**을 서버가 받아 팀 YOLO + v5_29 히트박스로 판정하고,
위험을 **폰 음성 · 진동**으로 먼저 알린다. 보호자는 별도 화면에서 **푸시 알림 · 위치 지도 · 실시간 영상 · 위험 구간 영상**을 본다.

```
 보행자 폰 (카메라 · 음성 · 항상 듣기 · GPS) ─┐                     ┌─ ① YOLO11s-seg (팀 가중치) + ByteTrack
                                             ├─▶ 서버 (FastAPI) ───┤  ② v5_29 히트박스: 사람 · 탈것 · 장애물 · 신호 바뀜
 라즈베리파이 카메라 (pi_camera.py) ─────────┘        │            ├─ ③ VLM 설명 (SJ 브랜치 Qwen2.5-VL, vLLM)
                                                      │            └─ ④ 특별 장면 묘사 (같은 VLM)
 보호자 폰 ◀── 알림 · 사진 · 위험 구간 영상 · 위치 · 실시간 영상 · 푸시 ──┘
```

## 빠른 시작
1. 이 저장소를 받고 `code/app` 폴더에서 `pip install -r requirements.txt` (파이썬 3.10+, GPU면 PyTorch CUDA 버전을 먼저 설치).
2. **Google Drive 의 팀 가중치 `final_10class_best.pt` 를 `code/app/weights/` 에 넣기.** (없으면 서버가 안 켜지고 넣을 곳을 알려 줘요.)
3. 서버 켜기: **`run.bat`** (맥/리눅스 `run.sh`). GPU 서버면 `run_gpu.sh`.
4. 폰 카메라 · 푸시 알림은 **HTTPS 주소**가 필요해요. 다른 터미널에서 `cloudflared tunnel --url http://localhost:8080` → 나온 `https://…trycloudflare.com` 주소를 폰에서 열기.
   - **아이폰은 사파리로** 여세요 (아이폰 크롬은 카메라 불가).
   - 폰에서 **홈 화면에 추가**하면 앱처럼 열려요. 아이폰 푸시 알림은 홈 화면에 추가한 앱에서만 켤 수 있어요(iOS 16.4+).
5. 보호자: 같은 주소 뒤에 `/guardian` + 터미널에 뜬 확인번호. 개발자 화면은 `/dev`.

## 폰 센서 기록 · 접속 키
- 앱을 켜면 GPS · 자이로 · 가속도 · 중력 · 방향 · 나침반을 자동으로 모아 `sessions/`에 Sensor Logger와 같은 형식의 CSV로 저장해요. 지금은 기록만 하고 판단에는 안 써요.
- 아이폰은 자이로 권한을 화면을 누른 순간에만 물을 수 있어요. 걸음 수 · 활동 · 기압계는 웹으로 못 읽어요.
- 공개 주소로 열 때는 `--key` 를 꼭 지정해요 (`https://주소/?k=키`).

## VLM (상황 설명 · 특별 장면)
SJ 브랜치의 vLLM 서버를 GPU에서 먼저 띄우면 자동으로 켜져요. 꺼져 있으면 서버가 알려 주고 **경고만** 냅니다.
```bash
# GPU 서버 (A5000): SJ 브랜치 code/p0
python serve_vllm.py qwen2_5-vl-7b --gpu-util 0.80      # → http://localhost:8000/v1
python server.py --device 0 --vlm-url http://localhost:8000/v1
```
- 히트박스 경고 중 **피하세요 · 멈추세요(긴급도 2 이상)** 에만 VLM 설명이 이어서 나와요 (위치 안내마다 붙이면 너무 많아서). 행동(멈추세요/피하세요)은 히트박스 판단을 그대로 따라요.
- 같은 VLM 서버로 불꽃놀이 · 벚꽃길 같은 **특별 장면**도 5초 간격으로 물어봐요.

## 라즈베리파이 카메라
라즈베리파이(제로 2 W · 4 · 5)에서:
```bash
sudo apt install -y python3-picamera2          # 카메라 모듈 (USB 웹캠이면 생략)
pip install websockets opencv-python-headless numpy
python pi_camera.py --server https://xxxx.trycloudflare.com --pin <확인번호>
```
그다음 보행자 앱 **설정 → 카메라 → 라즈베리파이 카메라**. 음성 · 진동은 그대로 폰에서 나와요. 서버 주소만 닿으면 되니 같은 와이파이가 아니어도 돼요.

## 경고 범위 · 녹화
- 보행자에게 말하는 것: **사람 · 탈것(자동차 · 버스 · 오토바이 · 자전거 · 킥보드) · 장애물(기둥 · 볼라드 · 벽 …) · 신호 바뀜 · 횡단 안내**. 계단만 뺐어요 (`HB_WARN_EXCLUDE`).
- 위험 구간 영상은 **사람 · 탈것 경고(긴급 · 주의)와 보행자 호출**일 때만 저장 (경고 5초 전 ~ 4초 후, 이어지면 최대 30초).
- 화면 색: 평소 파랑 · 주의(피하세요) 노랑 · 위험(멈추세요) 빨강.

## v5_29 실시간 이식

판정 코드는 **손으로 다시 쓰지 않았어요.** `hitbox_original_v5_29.py`(내 파일 그대로)를 `hitbox_build.py`가 읽어 `hitbox_core.py`를 만듭니다. 상수·함수·`for fr in frames:` 루프 본문·이벤트 만들기는 줄 단위로 같고, **입력을 공급하는 곳만** 바꿨어요(바꾼 곳은 `hitbox_build.py`의 `PATCHES` 표에 전부 있음; 원본이 바뀌면 변환이 에러로 멈춤).

| 원본 입력 (pass1이 파일로 저장) | 실시간 공급 |
|---|---|
| YOLO conf 0.2 추적 | 앱의 YoloTracker (hitbox면 자동으로 conf 0.2) |
| 배경 광류 쌍 | `FlowTracker` — `pass1_detect.RecordingMotion`과 같은 계산, 매 프레임 |
| 신호등 + 상자 안 색(HSV) | `LightWorker` — 별도 스레드, 3프레임마다 (바쁘면 건너뜀) |
| Mask2Former 바닥 분할 | `SurfaceWorker` — 별도 스레드, 5프레임마다 (GPU 필요) |
| group_speech | `OnlineSpeech` — 같은 규칙을 한 사건씩 |

**검증** (`python tests/test_hitbox_port.py`, 모델·GPU·영상 불필요): 가짜 장면(검출·광류·신호등·바닥)을 원본 `run()`과 실시간 코어에 똑같이 넣어 경고 사건이 **전부 일치**(7개), 말하기 묶기는 무작위 사건열 300개에서 원본과 일치. 즉 *같은 입력이면 같은 판정*이에요. 실제 영상에서의 정확도는 이 테스트로는 알 수 없고, 아래 차이 때문에 오프라인 결과와 100% 같지는 않습니다.

### 원본과 다른 점 (정직하게)
- 바닥 분할·신호등은 **비동기**라 몇 프레임 늦게 반영돼요 (원본은 같은 프레임 번호의 결과). 모델이 없거나 느리면 그 입력만 빠진 채 돌고, 화면 아래 상태줄에 `신호등 off / 바닥 off`로 표시돼요.
- 사람 경고의 "붐빔 걸러내기"(v5_13)는 앞뒤 ±2 s를 보던 걸 **지난 2 s만** 봅니다.
- 폰은 프레임이 ~10 fps이고 간격이 일정하지 않아요. 판정은 원본처럼 실제 시각(dt)으로 계산하지만, 15 fps로 튜닝된 시간 문턱(0.2 s 유지 등)이 조금 다르게 걸릴 수 있어요.
- 폰 영상은 긴 변 960 px로 보냅니다(원본은 최대 1920). `y2 − 지평선 > 15 px` 같은 **픽셀 문턱**은 영상이 작으면 먼 물체에서 달라져요.
- **카메라 높이**: 원본 기본 1.70 m. 폰을 가슴 앞에 들면 `--cam-h 1.3~1.5`처럼 실제 높이를 넣으세요 (거리 추정이 이 값에 비례).
- **세로 영상 가정**: 바닥 분할 위치 가정이 세로(540×960) 기준이에요. 폰은 세로로 들고 쓰세요. 가로 영상(XIAO)은 가로용으로 리사이즈해 돌리지만 원본에서 검증된 적은 없어요.
- 경고 문장은 SJ 실행 시스템 패치와 같은 형식: `정면 자동차가 다가와요. 멈추세요.` / `1시 방향 기둥, 11시 방향 자전거가 있어요.` / 우선순위 멈추세요 > 피하세요 > 위치 안내(폰 음성도 같은 규칙으로 끊고 이어감). 신호등 변경은 `신호등이 초록불로 바뀌었어요. 건너가세요.` — **"건너가세요"처럼 행동을 지시하는 문구는 안전 측면에서 팀이 한 번 더 정해 주세요** (`hitbox_trigger.compose`).

### 노트북만으로는 어디까지?
LG gram(CPU)에서는 YOLO가 느려 실시간이 어렵고, Mask2Former(바닥 분할)는 사실상 불가능해요. 현실적인 구성: **GPU 서버(A5000)에서 서버를 돌리고 폰은 그 주소로 접속**(폰 카메라는 HTTPS 필요, 서버가 외부에서 보이려면 같은 망/VPN/터널). 노트북에서는 `HB_SURFACE=0`으로 바닥 분할을 끄고 시험하세요 (`run.bat` 이 그렇게 켜요).

## 보행자 화면 / 보호자 화면

| 주소 | 누가 | 내용 |
|---|---|---|
| `/` | 보행자 | 위쪽은 상태를 말해 주는 영역(누르면 다시 듣기), 아래는 시작 · 중지 카드와 다시 듣기 · 보호자 호출 타일 |
| `/guardian` | 보호자 | 오늘 요약 · 위치 지도 · 최근 알림(사진 · 위험 구간 영상) · 실시간 영상 · 푸시 알림. 확인번호 필요 |
| `/dev` | 개발자 | 박스 · 단계 표시가 있는 확인용 화면 |

**보행자**
- **항상 듣기**(기본 켜짐): 버튼 없이 "시작", "그만", "다시 말해줘", "도와줘", "소리 키워", "천천히"를 알아들어요. 지나가는 대화를 명령으로 오해하지 않게 **짧은 말이거나 "세이아이"로 부를 때만** 받아요. 앱이 말하는 동안은 잠시 듣기를 멈춰요. 브라우저 음성 인식이라 안드로이드 크롬이 가장 안정적이고, 아이폰 사파리는 화면이 켜져 있을 때만 되고 가끔 끊길 수 있어요.
- 터치 안내(기본 켜짐): 한 번 누르면 이름을 읽고, 4초 안에 한 번 더 누르면 실행. 스크린리더를 쓰면 끄세요.
- 위치 공유(기본 켜짐): 안내 중에만 5초에 한 번 보호자에게 위치를 보내요.
- 경고는 효과음 · 진동 · 음성 순서, 급한 경고가 덜 급한 말을 끊어요. 영상 끊김 · 서버 재연결 · 배터리 20% 이하 · 카메라 권한도 음성으로 알려요.

**보호자**
- 알림 단계: 긴급 · 주의 · 안내 · 호출 · 연결 · 배터리. 위험 순간 사진(박스 표시)과 위험 구간 영상, 그때의 위치가 붙어요.
- **푸시 알림**: 설정 → 푸시 알림 켜기. 화면을 닫아도 폰 알림으로 와요 (HTTPS 주소 필요, 아이폰은 홈 화면에 추가한 앱에서).
- **실시간 영상**: 보행자 카메라 영상(인식 박스 포함, 약 7 fps). 보는 동안만 서버가 영상을 만들어요.
- **위치**: 지도(OpenStreetMap)에 보행자 위치와 오차 범위를 보여 줘요.
- 내역은 서버 `alerts/`에 최근 500건. 사진 · 영상에 보행자 주변이 찍히니 공유하지 마세요.
