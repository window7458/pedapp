# 화면 시험 (브라우저)

서버 없이 `web/index.html` 만 띄워 크롬(Playwright)으로 확인한다. `pip install playwright` 와 크롬이 필요하다.

| 파일 | 보는 것 |
|---|---|
| `speech_order_test.py` | 대답 중 보통 경고는 기다림 · 긴급 경고는 끊고 대답 다시 · 사용자가 말하는 중엔 경고 기다림 · 버스 물을 땐 대답 끝까지 경고 멈춤 · "511번" → "오백십일번" |
| `arrow_test.py [폴더]` | 미리보기의 걷는 방향 빨간 화살표 그림 (작게 · 크게) |
