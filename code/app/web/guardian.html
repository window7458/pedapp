보행자 앱과 연결해 주세요

보행자 폰에서 "보호자 연결해줘"라고 말하거나 설정의 보호자 연결을 누르면 QR이 떠요. 이 폰의 카메라로 찍으면 바로 연결되고, 다음부터는 자동으로 연결돼요.

QR을 못 찍는다면 확인번호를 넣어도 돼요. 보행자 앱에서 "보호자 번호 알려줘"라고 하면 읽어 줘요.

확인번호가 달라요.
